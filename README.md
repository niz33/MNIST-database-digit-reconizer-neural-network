# Handwritten digit reconizer neural network

Nothing special, just a simple neural network program that learns to reconize hand written digits in the form of 28*28 greyscale images.

In developtment right now.

Training and test data credit goes to the [MNIST database](http://yann.lecun.com/exdb/mnist/).

# Some details about the algorithm

* A multilayer neural network with 28*28 input neurons and 10 output neurons.

* Currently uses sigmoin and ReLU for activation functions.
